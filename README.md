# ToothPaste for Blender v0.9 (Blender 4.4 Compatibility)

This version is fully compatible with Blender 4.4 and includes all functionalities for SVG-to-Grease Pencil conversion, including mask handling, stroke splitting, and merging layers.

### Features:
- ✅ Paste SVGs directly from clipboard as Grease Pencil
- ✅ Supports all shapes - paths, rects, circles, and ellipses
- ✅ Supports SVGs created with Adobe Illustrator, Affinity Designer, Inkscape and others
- ✅ Split layers functionality into separate GP objects with one click
- ✅ Converts SVG to Grease Pencil strokes
- ✅ Works with grouped and ungrouped SVG structures


### Installation
1. Blender Preferences → Add-ons → Install this ZIP.
